# Dark Teal Primary Button

This is a custom dark teal Primary Button for the Unsubscribe Form.

The standard PrimaryButton from @zooniverse/react-components isn't used here since its teal colour scheme (as of Jul 2026) doesn't match accessibility requirements. Instead, we're creating a custom button that (more-or-less) conforms to the latest design on Figma.
